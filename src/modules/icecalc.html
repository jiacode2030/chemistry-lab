ICE tables & calculating equilibrium amounts

Given K and a starting mixture, how much of each substance is there at equilibrium? An ICE table keeps the bookkeeping straight.

The idea

Think of a tug-of-war that begins with a lopsided rope. Initial: where the rope starts. Change: how far the reaction pulls to get to balance, expressed with one unknown, x, times each coefficient. Equilibrium: initial plus change. Plug the E row into K and solve for x.

Below, you play the solver: slide x until Q reaches K. Q rises as the reaction moves forward, so there is exactly one x where Q = K. The graph shows this crossing. When K is small, x turns out small compared with the starting amount, and we may use the shortcut of dropping x from the subtraction, but only after checking the 5% rule.

Assumption upgrade Before, we assumed "x is small" without testing it. Now we check: if x is more than 5% of the starting concentration, the shortcut fails and we must solve the full equation (often a quadratic).

Try this

Predict x before you slide it.

  1. Make K very small and press Solve. How big is x compared with the starting amount?

    What you should see

    x is tiny (well under 5%), so ignoring x in the "start − x" term barely changes the answer: the shortcut and the exact answer agree.

  2. Now use K near 1 and see if the shortcut still works.

    What you should see

    x is a big fraction of the start, and the shortcut estimate is noticeably off. The 5% rule flags it: solve the full quadratic.

  3. Double the starting concentration with the same K. Does the percent that reacts stay the same?

    What you should see

    For N₂O₄ ⇌ 2NO₂ no: when one reactant makes two products, higher starting concentration means a smaller fraction reacts (Le Châtelier: more crowded favors fewer particles).

Worked example

N₂O₄(g) ⇌ 2NO₂(g), Kc = 0.36 at 100 °C. Starting from 0.100 M N₂O₄ with no NO₂, find the equilibrium concentrations.

Try it yourself first, then reveal one step at a time.

  1. Set up the table. I: [N₂O₄] = 0.100, [NO₂] = 0. C: −x and +2x. E: 0.100 − x and 2x.
  2. Write K. 0.36 = (2x)² / (0.100 − x) = 4x² / (0.100 − x).
  3. Try the shortcut and check it. Drop x in the denominator: 4x² = 0.036, x ≈ 0.095, which is 95% of 0.100. Far above 5%, so the shortcut fails. Solve the quadratic.
  4. Quadratic. 4x² + 0.36x − 0.036 = 0. x = [−0.36 + √(0.36² + 4·4·0.036)] / 8 = [−0.36 + √0.7056] / 8 = (−0.36 + 0.84) / 8 = 0.060. So [NO₂] = 2x = 0.120 M and [N₂O₄] = 0.100 − 0.060 = 0.040 M.

Common mistakes

  • Forgetting to multiply x by the coefficient (the table's change row is +2x, not +x).
  • Using the shortcut without checking: always test x ÷ start against 5%.
  • Reporting x as the answer. x is the change; the question usually wants the equilibrium concentrations (E row).
  • Putting the starting amounts of products into the table as zero when they aren't, or adding x to the wrong side.
  • Keeping a root that makes a concentration negative. Only one root is physically possible.

The 5% rule in one line

If K is small and the start is not tiny, then x ≪ start and you may write (start − x) ≈ start. Rule of thumb: the shortcut is acceptable when x/start < 5%. As a quick guide, that usually needs start/K to be about 400 or more.
